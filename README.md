# **RentEase — Rental Marketplace Platform**

---

## **Overview**

**RentEase** provides a digital marketplace where users can explore rental products, search
for suitable items, view product details, and manage rental-related activities.

The platform is built with a modern React frontend and a Supabase-powered backend/data layer,
with a modular API structure for application features such as authentication, rentals, 
products, checkout, reviews, service areas, and vendor operations.
